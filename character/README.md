Character Queries with Rick and Morty GraphQL API



This project contains GraphQL queries that fetch details of specific characters from the Rick and Morty GraphQL API

.



Objective



The goal is to write GraphQL queries to retrieve a specific character’s information using their ID.

For this task, we fetch characters with IDs 1, 2, 3, and 4.



Each query retrieves the following fields:



id



name



status



species



type



gender

How to Run the Queries



Open the Rick and Morty GraphQL Playground:

👉 https://rickandmortyapi.com/graphql



Copy the content from any of the .graphql files in this directory.



Paste the query into the playground and execute it.



The response will match the corresponding .json file in this repo.
